First Scala Program on EC2

1. Upload our test file "review.csv" via FTP

    (This file include the score from 1~5 for some restaurant )

2. Telnet to EC2 instance

3. spark-shell

4. testing code
    This code will count the average score and list top 10.

val lines = sc.textFile("review.csv") val rew_rates =lines.map(l => l.split("\\^")).map(l => (l(2), l(3).toFloat)) val sum_rew_rates = rew_rates.mapValues(x => (x, 1)).reduceByKey((x, y) => (x._1 + y._1,x._2 + y._2)) val avg_rew_rates = sum_rew_rates.map(x=>(x._1,x._2._1/x._2._2)) val pre_output = avg_rew_rates.sortByKey() val output = pre_output.sortBy(x=>x._2,false) output.take(10)

First Python Program on EC2

1. Upload our test file "review.csv" via FTP

    (This file include the score from 1~5 for some restaurant )

2. Telnet to EC2 instance

3. pyspark

4. testing code
    This code will count the average score and list top 10.

file=sc.textFile("review.csv") file_map = file.map(lambda x: x.split('^')).map(lambda x: (str(x[2]),float(str(x[3])))) sum = file_map.mapValues(lambda x: (x, 1)).reduceByKey(lambda x,y: (x[0] + y[0],x[1] + y[1])) avg = sum.map(lambda x:(x[0],x[1][0]/x[1][1]) ) output = avg.sortByKey() output.takeOrdered(10, lambda x: 5.0 - x[1]) output.take(10)
