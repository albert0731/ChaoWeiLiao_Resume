Install Spark and Scala on Ubuntu

2015-11-10
AmazonBig DataEC2ScalaSpark

Previous "Telnet to AWS EC2 instance"

Following are demonstration on AWS EC2 Ubuntu.

Install Java

sudo apt-add-repository ppa:webupd8team/java sudo apt-get update sudo apt-get install oracle-java8-installer

Install Git

sudo apt-get install git

Download Spark

This link is Spark 1.4.1 Pre-build for hadoop 2.6

Link might be change. 

Please check http://spark.apache.org/downloads.html , if following link missing.

wget http://d3kbcqa49mib13.cloudfront.net/spark-1.4.1-bin-hadoop2.6.tgz tar -xzf spark-1.4.1-bin-hadoop2.6.tgz

Install Scala

This demo use Scala version 2.10.4

wget  http://www.scala-lang.org/files/archive/scala-2.10.4.tgz tar -xzf scala-2.10.4.tgz sudo apt-get install scala

Environment setup

Check your path of Spark, Scala and Java first, then

vi ~/.bashrc

Attache following

# export environment variable export SPARK_HOME=/home/YourUserName/spark-1.4.1-bin-hadoop2.6 export SCALA_HOME=/home/YourUserName/scala-2.10.4 export JAVA_HOME=/usr/lib/jvm/java-8-oracle export PATH=$SCALA_HOME/bin:$SPARK_HOME/bin:$JAVA_HOME/bin:$PATH

Reload bashrc

cd . .bashrc scala -version #Scala should update to 2.10.4

Result

spark-shell
